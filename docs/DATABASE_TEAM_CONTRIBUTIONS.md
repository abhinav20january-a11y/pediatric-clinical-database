# Database Work Contribution

This project was completed collaboratively by three team members.

## Member 1 - Core Database Design

- Designed patient, guardian, staff, appointment, and visit tables.
- Added primary keys, foreign keys, checks, and soft deletion.
- Verified relationships and data integrity.

## Member 2 - Clinical and Dynamic Data

- Designed diagnosis, prescription, laboratory, and follow-up tables.
- Implemented dynamic fields using EAV-style relationships and JSON values.
- Added value history, form versioning, and audit support.

## Member 3 - Data, Queries, and Optimization

- Prepared synthetic demonstration data for patients and doctors.
- Created views, triggers, procedures, and evaluation queries.
- Added indexes, performance benchmarks, testing, and documentation.

## Shared Work

All members reviewed the final schema, tested database relationships, and prepared the project demonstration.
